# Template guide — sdlc-plan-stories-write

Guidance for filling this skill's templates, section by section. It used to sit in HTML
comments inside the template and example files; it is kept here, word for word, so those
files hold only visible content. Read the part for a template before you fill it. Do not
copy this guidance into the output.

## `templates/story.md.tmpl`

### Acceptance Criteria

Gherkin. One scenario per behaviour. Include unhappy paths. Each must be a pass/fail test.

### Out of scope

What this story explicitly does NOT cover. Keeps tests and implementation bounded.

### Notes / dependencies

Sequencing, data needs, design links, related stories.
