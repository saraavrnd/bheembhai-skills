# Template guide — sdlc-discovery-architecture

Guidance for filling this skill's templates, section by section. It used to sit in HTML
comments inside the template and example files; it is kept here, word for word, so those
files hold only visible content. Read the part for a template before you fill it. Do not
copy this guidance into the output.

## `examples/architecture.md`

### Top of file

Worked example: the SDLC-structured architecture.md for Learn Portal, built from the real
per-service discovery artifacts + integration-map. Shows how the machine findings become a
readable Architecture Overview while every line keeps its confidence tag and source.
