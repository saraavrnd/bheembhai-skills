# Template guide — sdlc-discovery-conventions

Guidance for filling this skill's templates, section by section. It used to sit in HTML
comments inside the template and example files; it is kept here, word for word, so those
files hold only visible content. Read the part for a template before you fill it. Do not
copy this guidance into the output.

## `templates/conventions.md.tmpl`

### Top of file

Discovery hand-off (system): conventions.md -> docs/discovery/_system/conventions.md
SDLC-standard Coding Conventions / Standards document. Readable sections on top, machine block
at the bottom. Every line keeps a confidence tag + source. A convention is usually `observed`
across N files, or `inferred` if it holds only in part of the code — say which.

### 1. Overview

2-4 sentences: how consistent the codebase is; whether conventions are enforced or just de-facto.
