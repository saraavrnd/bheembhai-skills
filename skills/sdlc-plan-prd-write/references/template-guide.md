# Template guide — sdlc-plan-prd-write

Guidance for filling this skill's templates, section by section. It used to sit in HTML
comments inside the template and example files; it is kept here, word for word, so those
files hold only visible content. Read the part for a template before you fill it. Do not
copy this guidance into the output.

## `templates/PRD.md.tmpl`

### 1. Problem & Opportunity

2-4 sentences: what problem, for whom, why now. No solution yet.

### 2. Target Users

The distinct user types and what each needs. Keep to the ones that drive requirements.

### 3. Goals & Success Metrics

Measurable. These define "working".

### 5. Feature Areas

Each feature area becomes a candidate EPIC in sdlc-plan-epics-create. Give each a stable code.

### 6. Functional Requirements

Atomic + testable. One capability per row. Group by feature area. Mark release.

### 8. Constraints & Assumptions

Platform, budget, deadlines, regulatory, dependencies. State assumptions you made.

### 9. Open Questions

Things to resolve before or during decomposition.
