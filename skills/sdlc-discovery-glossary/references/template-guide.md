# Template guide — sdlc-discovery-glossary

Guidance for filling this skill's templates, section by section. It used to sit in HTML
comments inside the template and example files; it is kept here, word for word, so those
files hold only visible content. Read the part for a template before you fill it. Do not
copy this guidance into the output.

## `templates/glossary.md.tmpl`

### Top of file

Discovery hand-off (system): glossary.md -> docs/discovery/_system/glossary.md
SDLC-standard Glossary / Domain Vocabulary document. Readable term tables on top, machine block
at the bottom. Every term keeps a confidence tag + source (where the term is defined/used in
the code or artifacts). A definition `inferred` from usage (not a docstring) is tagged so.

### 1. Overview

1-3 sentences: the domain this vocabulary covers and where terms were drawn from.
